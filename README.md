# Smart Travel Planner ✈️

A Django-based web application that helps users plan trips based on destination, budget, and duration.

---

## 🚀 Features

- User Authentication (Login / Signup)
- Plan trips with destination, budget, and days
- Save trips to database
- View all planned trips in dashboard

---

## 🛠️ Tech Stack

- Backend: Django (Python)
- Frontend: HTML, CSS
- Database: SQLite
