# Smart Travel Planner ✈️

A web application built using Django that helps users plan and manage their trips based on destination, budget, and number of days.

---

## 🚀 Features

- User Authentication (Signup & Login)
- Plan trips with destination, budget, and duration
- Save trips to database
- View all planned trips in dashboard
- Simple and clean user interface

---

## 🛠️ Tech Stack

- Backend: Django (Python)
- Frontend: HTML, CSS
- Database: SQLite

## ⚙️ How to Run the Project

1. Clone the repository:
   git clone https://github.com/your-username/smart-travel-planner.git

2. Go to project folder:
   cd smart-travel-planner

3. Create virtual environment:
   python -m venv venv

4. Activate virtual environment:
   venv\Scripts\activate

5. Install dependencies:
   pip install django

6. Apply migrations:
   python manage.py migrate

7. Run server:
   python manage.py runserver

8. Open in browser:
   http://127.0.0.1:8000/
